# 吞噬星空 · 写实行星与随机穿行版

可在 VS Code 编辑和预览的完整 HTML / CSS / JavaScript 项目。首页只有一个入口，游玩页全屏显示游戏，摄像头在右下角。

## 启动

1. 解压后，用 VS Code 打开 `star-tides-vscode` 文件夹，也可打开 `吞噬星空.code-workspace`。
2. 需要 Node.js 18+，终端运行 `npm run dev`。没有第三方开发依赖，无需 npm install。
3. 打开 `http://127.0.0.1:4173`。保存 CSS 会立即更新；修改 JS / HTML 会自动刷新并重开本局。
4. 结束时按 Ctrl+C。Windows 也可双击 START-PREVIEW.cmd。

附带 VS Code F5 的 Edge / Chrome 预览配置。需要系统能找到 node，且浏览器已安装；若内嵌预览不支持摄像头，使用独立 Edge / Chrome。端口占用时可运行 `npm run dev -- --port 4174`。不要直接双击 HTML。

## 这次的视觉方向

- 小：蔚蓝新生，蓝色海洋、陆地、云层、薄大气与昼夜阴影。
- 中：熔火失衡，地表经过干涸与褐色过渡，熔岩裂缝逐渐出现。
- 大：终焉湮灭，暗红岩壳、炽亮裂缝、冕焰与逸散碎石。
- 体积由总质量连续增长。到达阶段阈值后，纹理、颜色与光照用约数秒平滑混合。
- 分裂变成独立漂移、翻滚和碰撞的陨岩，带星光闪烁与流星尾迹；材质跟随本体阶段变化。
- 合并沿弧线缓缓收束，碎石淡出、行星浮现，恢复总体质量对应的大小与阶段。

这是本地生成的球面纹理与照明，不依赖远程图片。主要追求写实宇宙氛围，并非真实天文模拟。

## 成长、吞噬与音乐

| 阶段 | 总质量阈值 |
| --- | --- |
| 蔚蓝新生 | 4096（初始） |
| 熔火失衡 | 6800 |
| 终焉湮灭 | 11500 |

小行星持续从右侧进入。靠近较小的小行星会吸附，吞噬增加质量，出现扬尘、碎屑与低亮度冲击波。连续吞噬有连击反馈，每 10 颗释放引力震荡。

配乐为 Web Audio 实时生成：从稀疏低音逐渐加入音序、低鼓与高频节奏，速度由 58 BPM 提高至最多 146 BPM。总质量和累计吞噬数量分别影响紧张度；分裂不会让音乐突然变轻。吞噬越深入，声音低频越低、余震越长。分裂有岩体破裂声，合并有引力收束和成形低鸣，碰撞障碍有沉重冲击声。

右上角静音，设置中可调总音量、降低光效或减少动态。声音需要第一次点击才能播放。

## 不规则穿行障碍

- 首颗星球约在第 3 秒开始靠近，之后每隔随机 1.8–4.6 秒进入一颗，最多同时存在 9 颗。
- 从上、下、左、右随机边缘位置入场，具有不同半径、速度和斜向航线；不会连续三颗都从同一边进入。
- 各自穿过画面，完整离开屏幕后回收。不会统一向中心汇聚，也不会集体转向扩散。
- 边缘提示来袭方向，细线显示实际航行方向；轨道不追踪玩家。
- 完整行星是障碍，细小的不规则岩石可以吞噬。
- 碰撞击退并损失 7% 总质量，清除连击，随后有 1.6 秒保护。最低保留初始质量，累计吞噬数保留。
- 分裂后轮廓更小，适合穿越空隙；任一碎片受击会影响整体，合并中也会受击。

## 操作

| 动作 | 上半身体感 | 键盘 / 触屏 |
| --- | --- | --- |
| 移动 | 双手同时朝一边伸出 | WASD / 方向键或按住拖动 |
| 分裂 | 双臂向两侧张开 | 空格 / 分裂按钮 |
| 合并 | 缩拢身体，双手靠近胸前 | M / 聚合按钮 |
| 加速 | 常规移动 | Shift + 移动 |
| 暂停 | 右上角按钮 | Esc / 按钮 |

右下角开启摄像头，自然站立约 1 秒校准，确保肩膀、手肘和双手完整入镜。身体形态负责分合，双腕和前臂方向负责移动。这里不是手指级手势识别。动作放松后可再次触发。加载与校准期间游戏暂停。

使用本地 pose_landmarker_lite.task 与 MediaPipe Tasks Vision 0.10.21。首次启用体感需联网加载 JS / WASM，支持镜像与 GPU / CPU 回退。画面仅在本机识别，不录制、不上传，不申请麦克风。键盘模式的画面和音乐可离线运行。

## 在哪里修改

| 文件 | 内容 |
| --- | --- |
| src/config.js | 移动速度、碎片上限、入场间隔、碰撞损耗、粒子数量 |
| src/evolution.js | 阶段阈值、星球半径、音乐紧张度 |
| src/surfaces.js | 海陆云层、岩壳熔岩、球面旋转与光照 |
| src/renderer.js | 光效、尾迹、扬尘、行星与障碍绘制 |
| src/encounters.js | 障碍星球材质、随机穿行轨道、连续碰撞检测 |
| src/fragments.js | 碎片材质、碎片间碰撞、合并曲线 |
| src/world.js | 吞噬成长、分合、障碍入场与碰撞规则 |
| src/audio.js | 配乐节拍、音色、低频与音效 |
| src/camera.js / src/gestures.js | 上半身校准、动作阈值与识别 |
| index.html / styles.css | 首页、游戏浮层和手机布局 |

## 验证与使用范围

运行 `npm test`。27 项检查覆盖阶段变化、分合质量守恒、不同帧率碎片控制、音乐紧张度、四向穿行与屏外回收、随机尺寸速度和入场间隔、连续碰撞、击退与质量损耗、保护时间、初始质量下限、合并中受击、重置、体感分类和本地预览服务器。

已在浏览器核对首页、三阶段球面与陨岩材质，以及进入、分裂、移动、吞噬、合并、星球穿行和碰撞提示，未发现页面脚本错误。真人摄像头精度、耳机 / 音箱听感和你本机的 VS Code F5 环境仍需实际体验。程序音频不是预录制交响乐。
